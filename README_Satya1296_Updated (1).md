## 🚀 Featured Projects

### 🤖 [CareerVerse AI](https://github.com/Satya1296/CareerVerse-AI)
An AI-powered career and scholarship guidance platform. Uses Groq AI (Llama 3.3 70B) to give students personalized advice across 10+ career paths. The backend runs on FastAPI + MongoDB with JWT-secured logins, and it uses OpenStreetMap to help students find nearby colleges. On the frontend, there are 6+ React modules — including an AI counsellor, a skill profiler, and a scholarship matcher.

`React.js` `FastAPI` `Python` `MongoDB` `Groq AI` `JWT`

---

### 🛒 [E-Commerce Web Application (MERN)](https://github.com/Satya1296/E-commerce-Mern)
A full-stack online store where users can browse products, manage a cart, and place orders — all through a responsive React interface. Search, cart updates, and checkout are built to feel fast and easy to use.

`MongoDB` `Express.js` `React.js` `Node.js` `JavaScript`

---

A desktop app for booking bus tickets — search buses, pick seats, simulate a payment, and generate a ticket. Built with Java Swing and MySQL, using modular pages so it's easy to extend later.

`Java` `Java Swing` `JDBC` `MySQL`
